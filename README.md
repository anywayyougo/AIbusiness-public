# AI 实践作品集

> 这是围绕「AI 应用」独立完成的实践作品，聚焦两个方向：**用大模型做工具**，和**观察、评测大模型在情感交互中的表现**。

---

## 项目一：量化 AI 助手

模块化调用市场实时信息接口与网络搜索接口，接入 DeepSeek v4-pro 模型做解读输出。

- 多数据源模块化接入（A股行情 / 技术指标 / 全球市场 / 联网搜索）
- 模型自主 Function Calling，最多 8 轮工具联动
- 分析结果强制标注来源，杜绝模型编造数据

详见 [`量化AI助手/README.md`](量化AI助手/README.md)

---

## 项目二：主流模型角色扮演交互特点报告

以「角色扮演 + 情感陪伴」为切入点，对 DeepSeek、Kimi、豆包、千问、ChatGPT、Claude、Gemini、Grok 八款主流大模型开展系统性情感交互评测。

- 参考 Heart-Bench 与 ETrajEval 评测思想，设计「静态五问 + 动态情景模拟」双轨测试
- 建立可复用的评分标准（代入角色 / 识别情绪 / 符合逻辑 / 人格特性）
- 逐模型归因分析，提炼共性短板与优化方向（深层逻辑推理、长对话一致性）

详见 [`主流模型角色扮演交互特点报告/主流模型角色扮演交互特点报告.md`](主流模型角色扮演交互特点报告/主流模型角色扮演交互特点报告.md)
